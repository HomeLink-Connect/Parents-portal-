WISE PARROT PARENT PORTAL — installable app
============================================
Upload ALL of these together to the same HTTPS folder (Firebase Hosting, Netlify, GitHub Pages, cPanel with SSL):

  index.html              the portal (all logic + embedded logo)
  manifest.webmanifest    app name, colours, icons, shortcuts
  sw.js                   service worker (offline + fast loading)
  icons/                  app icons (Wise Parrot crest)

Installing is only offered over HTTPS (or localhost). Opening index.html directly from a
phone's files will still work as a normal page, but it can't be installed.

Android / Chrome : "Install the Wise Parrot app" button appears on the login screen.
iPhone / Safari  : the same button shows Share -> Add to Home Screen steps.

Themes: Midnight, Pearl White, Ocean, Orchid (palette button, top bar / login screen / Settings).
When you publish a new version, change VERSION in sw.js (now wp-parent-v5; next: v6) so phones refresh.

Admission numbers: parents register with the number from the school (e.g. G42026/001G) — generated by the Management System.
If only index.html is uploaded, the app still installs with the Wise Parrot icon (built-in fallback).

New in this version
- Homework (typed text, documents, photos) posted per class in the Management System shows for that grade's learners only.
- Message the School and Parents Community are WhatsApp-style chats: emojis, voice notes, photos, delivery ticks (sent / delivered / read).
- Transport shows the child's own bus; Events show time and venue; Announcements, Gallery and Events come from the Management System.
Firestore rules: if your rules list collections one by one, also allow read/write on "wp_files" (homework documents are stored there in small pieces).
